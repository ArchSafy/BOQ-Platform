# منصة إعداد وتسعير جداول الكميات (BOQ) وكراسات الشروط والمواصفات
### أمانة المنطقة الشرقية - الإدارة العامة للإشراف (مشاريع الأنسنة)

تطبيق ويب متكامل لإدارة وتسعير جداول الكميات (BOQ) وإصدار كراسات الشروط والمواصفات لمشاريع "الأنسنة" التابعة لأمانة المنطقة الشرقية بالمملكة العربية السعودية.

## المميزات الرئيسية:
1. **بيانات المشروع والمنافسة:** نموذج شامل لإدخال بيانات المشروع، الموقع، المدة، ونطاق العمل.
2. **بناء جدول الكميات التفاعلي:**
   - رقم البند
   - وصف الأعمال والمواصفات الفنية
   - الوحدة والكمية
   - السعر (الإفرادي، الإجمالي، والإجمالي كتابةً بالتفقيط العربي)
   - مصدر المواد (محلي / أجنبي) مع حساب نسبة المحتوى المحلي
   - الرمز الإنشائي (CSI / Spec Code)
3. **لوحة التحكم (Admin Panel):** واجهة مخصصة لإدارة الأقسام والبنود المعتمدة في الدليل وتعديل الأسعار والمواصفات دون تعديل الكود.
4. **نظام التصدير والمخرجات (6 مخرجات):**
   - جداول كميات Excel (نسخة مسعرة)
   - جداول كميات Excel (نسخة غير مسعرة للطرح)
   - جداول كميات PDF (نسخة مسعرة رسمية مع خانات الاعتماد)
   - جداول كميات PDF (نسخة غير مسعرة للطرح)
   - كراسة الشروط والمواصفات (Word .docx)
   - كراسة الشروط والمواصفات (PDF جاهز للطباعة)

## طريقة التشغيل:
افتح ملف `index.html` في أي متصفح حديث مباشرة.
